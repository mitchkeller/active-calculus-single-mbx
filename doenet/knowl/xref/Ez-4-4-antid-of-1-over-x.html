In Table 4.4.8 in Activity 4.4.7, we noted that for \(x \gt 0\text{,}\) an antiderivative of \(f(x) = \frac{1}{x}\) is \(F(x) = \ln(x)\text{.}\) Here we observe that a key difference between \(f(x)\) and \(F(x)\) is that \(f\) is defined for all \(x \ne 0\text{,}\) while \(F\) is only defined for \(x \gt 0\text{,}\) and see how we can actually define an antiderivative of \(f\) for all values of \(x\text{.}\)
