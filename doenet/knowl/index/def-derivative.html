Definition 1.3.2.

Let \(f\) be a function and \(x = a\) an input value in the function’s domain. We define the derivative of \(f\) with respect to \(x\) evaluated at \(x = a\), denoted \(f'(a)\text{,}\) by the formula
\begin{equation*} f'(a) = \lim_{h \to 0} \frac{f(a+h)-f(a)}{h}\text{,} \end{equation*}
provided this limit exists.
